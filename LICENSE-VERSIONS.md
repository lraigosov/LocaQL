# LocaQL — Version-to-Change-Date Map

This file tracks, per released version, the exact date each version's
Change Date (see `LICENSE` Section 5) occurs and whether it has already
converted to the Change License (MIT).

Change Date = release date + 3 years.

| Version | Released | Change Date | Status |
|---|---|---|---|
| v0.16.0 | 2026-08-12 | 2029-08-12 | Still under the LocaQL Source-Available License |
| v0.15.0 | 2026-08-11 | 2029-08-11 | Still under the LocaQL Source-Available License |

Update this table with every tagged release. A version's row moves to
"Converted to MIT" automatically once its Change Date passes — no action
is required beyond updating the Status column for accuracy.
